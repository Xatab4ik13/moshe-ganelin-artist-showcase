# План: редизайн по брифу клиента (Ар-Деко, мультиязычность)

Всё, кроме логотипа (логотип — отдельно через Nano Banana).

## Итерация 1 — Языки и структура
- Базовый язык сайта: английский. Русский UI убираем полностью.
- Переключатель EN / ES / POR сверху (кнопки в меню). Заготовка функционала: все тексты вынести в словарь переводов, переключение клиентское.
- Новое дерево меню:
  - HOME
  - ABOUT (выпадающее: Bio, Publications)
  - MUSIC (выпадающее: Organ, Orchestra, Piano, Transcriptions, Recordings)
  - POETRY (выпадающее: Russian, English, Spanish, Portuguese)
  - CONCERTS
  - GALLERY
  - CONTACT
- Русский контент остаётся только как подраздел POETRY → Russian.

## Итерация 2 — Ар-Деко визуал
- Применить шрифты из архива клиента (Metropolis 1920 / Partita Deco для заголовков, Poiret One / Goudy Old Style — проверим подборку по лицензиям/весу).
- Ар-деко орнаменты: золотые геометрические рамки, лучи/sunburst, ступенчатые линии; убрать «нейроновские» элементы.
- Цветовая гамма: доработать по пожеланию — чёрные зоны сделать торжественнее, блог не голый; держим направление белый/графит/золото + петроль.
- Плавные анимации переходов между страницами.
- Крупнее основной текст везде (клиент: слишком мелко).

## Итерация 3 — Контент страниц
- HOME: вопрос по hero (см. уточнения ниже).
- ABOUT: фото «Ганелин в профиль за органом»; фото с вручением премии перенести в биографию; подраздел Publications.
- MUSIC: подразделы Organ / Orchestra / Piano / Transcriptions / Recordings.
- CONCERTS (афиша): другое фото в шапке.
- POETRY: 4 языковых подраздела, тексты — шаблоны.
- GALLERY, CONTACT — по текущей структуре, перевод на EN.

## Итерация 4 — Деплой
- git pull / build / restart на VPS, проверка медиа.
