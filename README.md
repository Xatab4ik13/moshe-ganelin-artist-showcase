# Moshe Ganelin — официальный сайт

Сайт-визитка музыканта: композитора, органиста, пианиста. Концерты, музыка, видео, блог, галерея и контакты.

Домен: https://moshearielganelin.com

## Разработка

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Сборка и запуск

```sh
npm run build
PORT=3000 node .output/server/index.mjs
```

Инструкция по деплою на VPS — в `DEPLOY.md`.
