# Moshe Ganelin: Artist Showcase

Делай новый проект. Домен у нас будет https://moshearielganelin.com
Сайт-визитка для музыканта: композитора, органиста, пианиста. Видео выступлений, фото, афиши концертов и т.д.
Референсы:
https://www.olivierlatry.com/
https://www.david-garrett.com/en/.
По гамме не придумали ничего лучше условно-классической: белый+графит+красные акценты
1. Главная - ближайшие концерты, ищбранное, пара публикаций с переходом на все публикации, фотографии и соцсети

2. О музыканте - биография

3. Афиша - каталог текущих + архив

4. Музыка - там условно разделы по направлениям + для каждой композиции ссылки + ноты и тд

5. Видео (каталог тоже по сути с описанием)

6. Блог

7. Галерея

8. Контакты
